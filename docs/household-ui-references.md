# 家計簿の画面の参考（2026-11-17 調査）

上位の家計簿アプリの公開のヘルプ・ストアの説明・公式ブログから、**呼び名と画面の型** を集めた。方針は「よく使われている言葉と型をそのまま借りる」。
借りるのは一般の言葉（収支・振替・未分類・計算対象外など）と画面の型だけ。各社が作った機能の名前（シェアボード・ペア家計簿・自動で経理・Free to Spend など）、ロゴ・配色・イラスト・画像は使わない（`docs/ui-references.md` と同じ）。

- 記号：★ = 調べたアプリでいちばん多い呼び名。（推測）= ページで確かめられなかったもの。
- 略号：MF = マネーフォワード ME、OS = OsidOri、OB = ワンバンク（旧 B/43。2025-03 に改名）、MT = Moneytree、OR = おカネレコ。
- 画面の文言は短く。説明の文はなし、アイコン＋2〜6字が基本。台帳の勘定の名前（`Expenses:Food` など）・借方／貸方・「中間表現」などの内部の名前は画面に出さない。

| 操作 | 中項目の［＋ 追加］、名前の変更、並べ替え、初期値は目のアイコンで隠す（消さない）、足したものは消す | OS（目のアイコンで隠す・赤の丸で消す）、MT（名前・アイコン・親カテゴリ） |
| 分類ルール | お店の文字 → カテゴリ（振替にする も含む）。一覧と［追加］ | MF 分類ルール・振替ルール、Actual |

### 3.7 家族の共有

| 項目 | 型 | 参考 |
|---|---|---|
| 単位 | **口座ごと** に持ち主（人）と見える範囲 **共有／自分だけ** を決める。入出金は口座の設定を受け継ぐ | Zaim（口座ごとの共有設定）、MF シェアボード（金融機関ごと）、Monarch Shared Views（口座の持ち主を取引が受け継ぐ） |
| 初期値 | 新しい口座は **自分だけ**。共有は人が切り替える | Zaim（初期は共有しない） |
| 見せ方 | 家計簿・入出金・口座の上に人のチップ：**全員**・人ごと（頭文字）。行には持ち主の頭文字、自分だけの口座は 🔒 | Monarch（Owners の絞り込み）、Lunch Money（Linked by） |
| 自分だけの口座 | 他の人には名前・残高・合計への寄与も見せない。本人の画面では合計に「🔒 を含む」 | MF シェアボード（お小遣い口座は自分だけ）、Monarch（隠せないのが不満点 → 逆を採る） |
| 切替え | 共有 ⇄ 自分だけ はいつでも両方向。変えた人と日時を残す（AGENTS.md 4・6） | OS は家族 → 個人に戻せない（採らない） |
| 他人の記録 | 共有の口座でも、編集は持ち主と管理者だけ | Zaim（相手の記録は編集できない） |
| 既存との関係 | 共有の設定は既存の「共有設定」（`settings/consents`・`access.py`）と同じ画面・同じ同意の仕組みに置く | — |

## 5. 避けること

| 避けること | 代わり | 根拠 |
|---|---|---|
| 台帳の勘定の名前（`Expenses:Food`・`Assets:Bank`）、借方・貸方、仕訳 | カテゴリ名・口座名だけ | ユーザーの指摘（内部の名前を出さない） |
| 「大項目」「中項目」を入力の欄の名前に出す | 「食費 › 外食」と並べる | MF も選ぶ画面では名前だけ |
| 画面の上の説明の文・ツアー | アイコン＋短い語、空の状態は1行＋1ボタン | ユーザーの好み |
| 取り込んだ明細を黙って確定する | 登録待ち → 人が登録 | AGENTS.md 4 |
| 件数の上限も確認もない「全部登録」 | 25 件まで・件数と合計の確認を1回 | Copilot・Lunch Money |
| スワイプだけで操作 | 同じボタンを画面にも出す | YNAB・Monarch はボタンも持つ |
| 灰色だけで「計算対象外」を示す | 文字「計算対象外」も | 色だけに頼らない |
| 家族の誰にも隠せない口座 | 口座ごとに「自分だけ」 | Monarch の不満点（隠せない） |
| 共有 → 自分だけに戻せない | 両方向に切替え | OS の一方通行 |
| 振替（カードの引き落とし・ATM）を支出に数える | 振替にして収支から外す | MF・OS（振替は計算対象外） |
| 金額を丸める・「約」 | 円単位でそのまま | AGENTS.md 5 |
| カテゴリから控除額を出す・「控除できます」と言う | 「関係しうる書類」の目印だけ。計算は okura-gov | AGENTS.md 5 |
| 各社の機能の名前（シェアボード・ペア家計簿・自動で経理・わけわけ 等）、キャラクター・広告の帯 | 一般の語 | `docs/ui-references.md` |
| 初回に予算・カテゴリの設定を求める | 初期値で始め、あとで設定 | MF・Zaim は初期値で使える |
