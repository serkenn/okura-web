# 画面の参考（2026-11-17 調査）

似たサービスの公開のヘルプ・手引き・ストアの説明・記事から、**画面の型（配置・流れ・操作）だけ** を借りた。
製品名・機能名・ロゴ・配色・イラスト・文言・スクリーンショットは使わない（作成コーナーと誤認される配色も避けた）。
（調査の範囲：公開ページだけ。freee のヘルプの本文は取得できず、検索結果の抜粋に拠る。）

## 取り入れたもの

| 画面 | 型 | 参考 |
|---|---|---|
| ホーム | 「今やること」を1枚にまとめ、件数のバッジ → 各画面へ | タックスナップ（今やること）、弥生（ホーム） |
| ホーム | 人ごとのカード（主な値と、いちばん近い境目の「あと○円」） | 扶養の壁の計算サイト（sum.money・記事） |
| ホーム | 計算の前提をバッジで常に出す（対象の年分・okura-gov の版） | sum.money（税制年度のバッジ） |
| ぺたっと貼る | ドロップゾーンと「選ぶ」を同じ場所に。貼るときに持ち主と書類の種類（あとで変えられる） | MF クラウド確定申告（仕訳候補） |
| ぺたっと貼る | タブ：未登録／確認待ち／登録済み／対象外。重複は中身のハッシュで検知 | freee（未登録・登録済み）、MF、タックスナップ（重複の検知） |
| 写真と入力 | 左に原本（拡大・縮小・回転・別のタブ）、右に入力。「確定して次へ」「もう1件」 | MF（仕訳候補の詳細）、作成コーナー（もう1件入力する） |
| 写真と入力 | AI が読んだ欄は「AI・未確認」の印（文字と色の両方）。人が「確かめた」に印を付けるまで確定できない | 調査の提案（MF に区別の表示が見当たらなかった点を差別化） |
| 決めること | 大きな答えのカード。答える前に「この答えだと何が変わるか」（候補ごとの値）を見せる。「わからない・あとで」 | 作成コーナー（はい／いいえ）、タックスナップ（スキップ）、調査の提案 |
| 結果 | 境目のゲージ。年齢の境目は「○歳になる日」。前提・根拠は折りたたみ | 扶養の壁の記事（タウンワーク・オールアバウト）、sum.money |
| 申告書に写す | 段の表示（①〜④）、欄ごとの値とコピー・「写した」の印 | 作成コーナーの手引き（入力の順・ステップ） |
| 家族 | 頭文字のアイコン、人ごとの共有の状態のチップ | 調査の提案 |

## 取り入れなかったもの

- スワイプで分類する操作（扶養などの重い判断には向かない）。
- 有利な方を自動で選ぶ表示（okura-gov は最適化しない：D22 S20。候補ごとの値を並べるだけ）。
- 製品名・機能名（例：各社の受信箱や仕分けの機能の名前）、キャラクター、作成コーナーの配色。

## 2026-11-17 の作り直し（「上位のソフトの UI に寄せる」）

型だけを借り、ロゴ・名前・配色・文言・イラストは使わない（自作の線画アイコン、外部のフォント・画像なし）。

| 画面 | 寄せた型 |
|---|---|
| 枠 | 業務 SaaS のダッシュボード（白い面・細い罫線・黒の主ボタン・グループ分けした左のナビ・下に自分・上に検索 Ctrl+K） |
| ホーム | 指標の帯（KPI）・「申告までの道のり」のチェックリストと進み具合・人ごとのカード・右に計算の状態と最近の動き |
| 書類 | 経費精算ソフトの受信箱（ドロップの帯・状態の切替え・サムネイルつきの表）と、全高の分割画面（左に暗い背景の原本、右に入力・下に固定の確定ボタン、前後の書類へ） |
| 決めること | 申告ソフトの面接（左に質問のレール、一問ずつ大きな問い、ラジオのカードに答えごとの値、「なぜ聞くのか」、戻る・あとで・次へ） |
| 結果・申告書 | 密度の高い表、右から出る詳細のシート、段の表示（①〜④） |
