# 家族で確かめる：ツリーテスト（新しいメニューで迷わないか）

目的：`docs/ia-model.md` のメニュー（もの）で、家族が用事を **迷わず・3手以内** で済ませられるかを確かめる。
画面の見た目ではなく「どこを押すか」だけを見る。1人 10〜15 分。

## やり方

1. スマホで okura-web のホームを開いた状態から始める（試す人のスマホ）。
2. 下の「問題」を1つずつ読み上げる。**押す場所を探してもらうだけ**（入力・登録はしない。押したら戻ってよい）。
3. 見る人は、問題ごとに「最初に押した場所」「たどった道」「迷った（戻った）か」「かかった秒数」を記録する。
4. 正解の道でなくても、たどり着けば「遠回りで成功」。15 秒以上止まったら、そこで止めて次へ（「失敗」）。
5. 終わったら「どこが分かりにくかったか」「その場所を何と呼ぶか」を一言ずつ聞く（呼び名の手がかり）。

試す人：管理者（息子）・父・母。親は招待リンクで答える画面だけでもよい（問題 9）。

## メニュー（試す時点）

```
ホーム（やること・家族）
├ 家計簿（収支・予算・推移）
├ 書類（撮る・一覧）
├ 確定申告（年分 → 人 × 段 → 1人の申告：①書類と記録 ②決めること ③結果 ④申告書）
└ その他
   ├ 入出金（登録待ち・未分類）
   ├ 口座
   ├ 家族（人 → 人のページ）
   └ 設定
```

## 問題と正解の道

| # | 問題（読み上げる） | 正解の道（3手以内） | 見たいこと |
|---|---|---|---|
| 1 | 病院の領収書が手元にある。アプリに入れて | 書類（撮る） | 「撮る」が書類のタブだと分かるか |
| 2 | お母さんを扶養に入れたままでいいか、決めるところを探して | 確定申告 → 母 → ②決めること（またはホームのやること → 決めること） | 決めることが確定申告の中にあると分かるか |
| 3 | 今年、お父さんの税金がいくらになるか見て | 確定申告 → 父 → ③結果 | 結果が確定申告の中にあると分かるか |
| 4 | 作成コーナーに写す金額を出して | 確定申告 → 人 → ④申告書 | 申告書の段を見つけられるか |
| 5 | お父さんがあといくら稼ぐと扶養から外れるか見て | ホーム → 家族の父のカード（壁）、または その他 → 家族 → 父 | 壁が人のところにあると分かるか |
| 6 | 今月、食費にいくら使ったか見て | 家計簿 | 家計簿の最初の画面で分かるか |
| 7 | カードの明細で、まだ登録していないものを片付けて | ホームのやること → 登録待ち（または その他 → 入出金 → 登録待ち） | 「登録待ち」の入口を見つけられるか |
| 8 | AI が読んだ給与明細を確かめて | ホームのやること → 確認待ち（または 確定申告 → 人 → ① の「確かめる」） | 「確認待ち」が分かるか |
| 9 | （親）送られてきたリンクで、質問に答えて | 招待リンク → 答える | 1問ずつ答えられるか |
| 10 | 家族に金額を見せる・見せないを変えて | その他 → 設定 → 共有設定 | 設定の中の場所が分かるか |

## 結果の見方

- **最初に押した場所** が正解の道の1手目と違う問題が、2人以上で出たら → その場所の呼び名か置き場所を変える。
- **失敗** が1人でもあれば → その用事の入口を、ホームのやること・人のページなど、最初に押された場所にも足す。
- 「一言」で出た呼び名が今の呼び名と違えば → 呼び名の候補にする（例：「確定申告」より「税金」と呼ぶ、など）。
- 結果（記録の表）を貼ってもらえれば、直す場所の案を作る。
