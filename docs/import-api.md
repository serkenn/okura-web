# 家計簿の取り込みの API（取得元 → okura-web）

okura-web は銀行・カード・通販のサイトから取ってこない。取ってくるもの（Okura、銀行の CSV を変換するスクリプト、ほかのツール）が、
この API に送る。送った取引は「取り込み待ち」に入り、画面で人が確定すると家計簿の台帳（`book/book.jsonl` → `book/book.beancount`）に入る。

## 認証

設定 → AI連携 でトークンを作るとき、権限に **import** だけを選ぶ。import のトークンは取り込み待ちに置くことしかできない
（家計簿・計算の結果・記録を読めない。確定もできない）。

```
Authorization: Bearer okt_…
```

## POST /api/v1/imports

```json
{
  "source": "okura",
  "account": {"key": "jcb-main", "kind": "card", "label": "JCBカード"},
  "transactions": [
    {"id": "2026-11-01-0001", "date": "2026-11-01", "amount": -3200, "payee": "スーパー", "memo": "食料品"},
    {"id": "2026-11-05-0002", "date": "2026-11-05", "amount": 500, "payee": "返金"}
  ],
  "balance": {"date": "2026-11-05", "amount": -2700}
}
```

| 欄 | 中身 |
|---|---|
| `source` | 取得元の名前。英数字と `_ . : -`（64文字まで） |
| `account.key` | 取得元の中の口座の名前（同じ key は同じ口座に入る）。英数字と `_ . : -` |
| `account.kind` | `bank`・`card`・`cash`・`emoney`・`other` |
| `account.label` | 画面の名前（最初の確定のときに使う。後から画面で変えられる） |
| `transactions[].id` | 取得元での取引の ID。**同じ `source` と `id` は二度入らない**（取り消した取引も含む） |
| `transactions[].date` | `YYYY-MM-DD` |
| `transactions[].amount` | 整数の円。口座から見た向き：入金は正、出金（支払い）は負。カードの利用は負 |
| `transactions[].payee`・`memo` | 相手・メモ（制御文字は落とす） |
| `balance` | 任意。その日の終わりの残高（カードは負＝未払い）。合わないときは台帳に書かず、画面で「合わない」と出す |

1回に 2000 件まで。応答：`{"ok": true, "batch_id": "imp-…", "accepted": 2, "duplicates": 0}`（新しいものがなければ `batch_id` は null）。

## 確定（画面の人）

- 取り込み待ちを開き、カテゴリを直して「確定」。初めての口座は、持ち主（家族のだれか、または共有）を決める。
- 確定すると、取引は `add`、残高は `balance` の出来事として家計簿の台帳に追記される。上書きはしない（直すときは `correct`）。
- 取り消し（使わない）もできる。取り込み待ちの記録は消さずに印を付ける。

## 申告の計算との関係

家計簿の台帳は、申告の台帳（`ledger/`）と別に置き、判定コアの計算には入れない。医療費・寄附などを申告に使うときは、
画面で「申告に使う」を選び、事実台帳の記録（医療費の支払など）として人が確定する。
